**Calculator**
A simple calculator that recognises pi, exponent, root. It also remembers your results and puts them in a graph for visualisation.

**Used:**
1. **Streamlit** for interface
2. **NumPy and Math** for calculations
3. **Regular Expression (re)** for text/calculation handling
4. **Pandas** for data handling
5. **MathPlotLib** for data visualisation


**Future additions:**
1. Recognising complex numbers, letters, symbols, trigonometric functions
2. Recognising button Enter
3. Automatically switching from button to textbox when using buttons
